G2 is decomposed into four parallel prerequisite packages followed by security and integration review, with answerability deferred behind human decisions.

Evidence

  • T-030 embedding provenance, T-031 vector compatibility, T-032 FTS5 shadow indexing, and T-033 evaluation harness may run independently after GO.
  • T-034 security review depends on all four prerequisite outputs.
  • T-035 integration review depends on T-030 through T-034 and their sanitized receipts.
  • Every package has a dedicated no-remote worktree, sanitized database copy, output receipt, acceptance criteria, and rollback boundary.
  • The answerability lane is not provisioned because human baseline scoring and approved no-answer wording remain unresolved.

Limitations

This graph authorizes no build by itself. Per-builder GO instructions are required before execution.
