A routing-layer policy blocked the existing inline style and script even though the page returned HTTP 200. The narrow hotfix restored the interface without changing retrieval or data.

Evidence

  • Both Pocket routes, API health, and the logo asset return HTTP 200.
  • A fresh browser rendered the branded dark gradient, white text, loaded logo, and two-column layout.
  • The fresh browser console contained no CSP violations.
  • The JavaScript question path executed and rendered the expected missing-access response.
  • The Google authorization page retained its original strict security policy.

Limitations

The current interface still uses inline assets. The planned build should move them into versioned external files. Rollback is promotion of the immediately previous routing deployment followed by route and browser verification.
